## 2. 주제 후보와 선택

| | ① 페르소나가 긍정 편향을 증폭한다 | ② 트윈은 요약에 머문다(전형 의존) |
|---|---|---|
| 근거 | A2 gap 단조 증가, 긍정 문항은 0 | 거리 삼각형, B1 무변화, 순기여 ≈ 0 |
| 강점 | 효과 크고 방향이 선행연구(Capraro 2024, Twin-2K outcome bias)와 맞으면서 "페르소나가 악화시킨다"는 **새 관찰**. 개입 실험이 자연스럽게 따라옴 | 트윈 연구의 근본 질문. Funhouse ①②의 1인 확장 |
| 약점 | 부정 문항 n=9 | "안 된다"가 결론이면 밋밋함. k·전체 삽입·파인튜닝까지 가야 이야기가 됨 |

**선택: ①을 주제로, ②를 ①의 메커니즘 설명으로 묶는다.**
> 왜 페르소나가 긍정화를 키우나 → 요약의 "따뜻한 할머니" 서술이 발췌(실제 발화)보다 세게 작동하기 때문(전형 의존). 발췌가 안 먹히는 이유(②)가 곧 긍정화의 원인(①).

**논문 한 문장 (가안)**: 공인 인터뷰 자료로 만든 디지털 트윈은 본인의 부정적·단호한 발화를 체계적으로 온건화하며, 이 긍정 편향은 페르소나 정보(요약·발췌)를 더할수록 커진다 — 그 메커니즘은 요약 전형이 실제 발화를 덮는 것이고, 지시·발췌 가중으로 완화 가능한지를 검정한다.

## 3. 본실험 전 반드시 할 것 (주제의 전제 검증)

| 순서 | 작업 | 이유 | 비용 |
|---|---|---|---|
| 0-1 | **판정 모델 교체 재채점** — 다른 패밀리(OpenAI 또는 Claude)로 A1 출력 중 부정 문항 전부 + 무작위 50쌍 재채점 | "긍정화 +1.4"가 DeepSeek 채점자 취향이 아닌지. 이게 무너지면 ①이 무너짐 | 수백 회, 수천 원 |
| 0-2 | **50문항 태그 검수** — valence·ground·fame, `reviewed: true` | 부정 문항 분류가 틀리면 A2 전체가 흔들림 | 1시간 |
| 0-3 | **부정 문항 확충** — Holdout 270 전체에서 valence ≤ −1 문항을 모두 추출(예상 30~50개) | n=9 → 30+ | 태깅 220회 + 검수 |
| 0-4 | 임베딩을 sentence-transformers(e5)로 교체, `retrieve.py --backend st` 재실행 | TF-IDF는 표현 겹침만 봄 | 로컬 설치 |
| 0-5 | C1 환각 검증 — 기존 출력의 일화 395개를 Train·G1과 대조 | 호출 없음, 보고 가치 큼 | 반나절 수작업 |

## 4. 본실험 설계 (우선순위 순)

### 4-1. A2 확장 + D3·D4 — 긍정화는 프레임·절차에 따라 변하나 (주제 본체)
- 문항: 부정 문항 30개 + 대조 긍정 문항 30개
- 조건: G0 / G1 / G2 (G3는 보조)
- 조작: **프레임 4종**(중립 / 방송 진행자 / 구독자 댓글 / 3인칭) × **CoT 유무**
- 반복: T=1 × 10회 + T=0
- 호출: 60 × 3 × 4 × 2 × 11 ≈ 16,000 → 프레임은 G2만, CoT는 G1·G2만으로 줄이면 ≈ 5,000
- 지표: valence_gap(부정/긍정), agree_stance, 프레임 간 답변 거리
- 가설(탐색적): 댓글체·CoT에서 긍정화가 더 커진다(사회적 바람직성 발동) / 3인칭에서 줄어든다

### 4-2. G1 분해 — 요약의 어느 요소가 긍정화를 만드나 (메커니즘)
- G1 요약을 세 변형으로: **생애만** / **가치관만** / **말투만** (+ 전체)
- 부정 문항 30개 × 4변형 × 11회 ≈ 1,300회
- 예상: "가치관"(나눔·긍정·늙음과 친해지기) 문단이 긍정화의 주범; "말투"(단호·직설) 문단은 완화

### 4-3. 개입 — 긍정화를 줄일 수 있나 (처방 = 기여)
| 개입 | 내용 |
|---|---|
| 지시 | G1에 "노라는 단호하고 직설적으로 말하며, 비판할 때는 돌려 말하지 않는다" 추가 |
| 발췌 가중 | retrieve 시 valence ≤ −1인 Train 발화를 우선 포함(k=20 중 10개 보장) |
| 발췌 확대 | k=40 / Train 전체 삽입(200k 컨텍스트 모델) |
| 모델 교체 | 생성 모델 2종(DeepSeek + 다른 패밀리) |
- 부정 문항 30개 × 개입 4종 × 11회 ≈ 1,300회
- 성공 기준: 부정 문항 gap이 G0 수준(+0.8) 이하로 내려오고, B1 충돌 문항 끌림 지수 > 0.5

### 4-4. 보고만 하는 것
- 거리 삼각형(e5 재계산), 층별, E1 — 본실험 조건에서 재산출해 §1 표와 비교
- A3 온도(T=0 / 0.7 / 1) — G2만, 부정 문항 30개

### 4-5. 돌리지 않는 것 (이유)
- **D1 순서 효과·D2 비지정 맥락**: 본인 자료와 대응 불가, ①과 연결 약함 → 별도 소논문 감
- **C2 지식 과잉·E2 시간 드리프트**: 부록 수준. 여력 있으면 C2 10문항만
- **E1 심화**: 누출 징후가 없었으므로 가명 처리는 유지하되 더 파지 않음

## 5. 일정 (가안)

| 주 | 할 일 |
|---|---|
| 1 | §3 전제 검증 0-1 ~ 0-5 |
| 2 | 4-1 실행·분석 → 긍정화가 재현되는지 중간 판단 |
| 3 | 4-2 분해, 4-3 개입 |
| 4 | 4-4 보고 지표, 코더 2인 채점 100쌍(κ/ICC), 쓰기 |

중간 판단 규칙: 2주차에 다른 패밀리 판정에서도 부정 문항 gap ≥ +0.8이고 G2 > G0이면 ① 유지. 아니면 ②(전형 의존)로 주제를 옮기고 4-3의 "발췌 확대·파인튜닝"을 본체로.

## 6. 발표 마무리 한 줄
> 파일럿은 **긍정 편향을 페르소나가 증폭한다**는 신호를 찾았고, 본실험은 그 메커니즘(요약의 어느 요소가)과 처방(지시·발췌 가중으로 줄일 수 있는가)을 검정한다.
