세부 설명

  • 이 이론의 표준 조사법(래더링)이 "왜 그게 중요한가"를 반복해 묻는 인터뷰라 자료원과 맞음
  • 처음 보는 제품도 속성으로 쪼개면 저장된 사슬에 연결됨 → 새 질문에 대한 일반화 근거
  • 보조 후보: 다속성 태도 모형, 자아-브랜드 일치 이론
  • 찾을 것: 원 문헌(Gutman 1982, 래더링) 확인, LLM·온톨로지와 결합한 선행 연구가 있는지

예측 엔진 후보 — LLM은 한 번만, 이후는 다항로짓(MNL) + 베이즈 갱신 가안

LLM은 온톨로지를 채우는 데만 쓰고, 예측과 갱신은 통계 모형이 맡는다. 새 평가가 들어와도 LLM을 다시 부르지 않는다.

① LLM (한 번)기록에서 사슬 추출, 제품을 속성으로 분해, 첫 짐작을 금액으로 답함
▶
② 사전분포속성별 가중치의 출발값 = LLM의 첫 짐작 + 본인 사슬 + 비슷한 사람들의 기록
▶
③ MNL로 예측제품 속성 × 가중치 → 선호 확률과 불확실성
▶
④ 베이즈 갱신실제 평가가 생기면 가중치만 고침. 불확실하면 보류·직접 질문

근거 ② Qiu 외 (2025) — Bayesian Teaching

선택을 볼수록 더 잘 맞히게 되는가 · 5번째 라운드 정확도
기존 LLM (1번째도 37%)37%
정답만 보고 훈련61%
베이즈 계산법 따라 하기 훈련76%
베이즈 계산법 자체81%
LLM은 선택을 더 보여 줘도 늘지 않았다(37% → 37%). 갱신은 LLM이 아니라 계산법이 잘한다.
세부 설명
  • 근거 등급과의 연결 — 본인 기록이 적을 때는 비슷한 사람들의 평균(사전분포) 쪽으로 기울고, 본인 기록이 쌓일수록 본인 쪽으로 옮겨 감. "언제 빌리고 언제 본인 것을 쓸지"가 규칙이 아니라 확률 계산으로 정해짐
  • 보류의 기준이 생김 — 예측의 불확실성이 크면 보류. 어떤 질문을 직접 물으면 불확실성이 가장 줄어드는지도 계산 가능
  • 장점 — 호출 비용이 없고, 같은 입력에 항상 같은 답(LLM의 응답 흔들림·순서 민감성 회피), 가중치가 보여 설명 가능
  • 걸리는 점 ① — MNL은 "여러 대안 중 하나를 고른다"는 선택 자료가 필요. 리뷰는 별점이라 선택 집합을 따로 구성하거나 순서형 모형으로 바꿔야 함
  • 걸리는 점 ② — MNL은 속성 가중치의 합으로 판단한다고 가정. 속성 → 결과 → 가치 사슬과 어떻게 이을지(예: 가치가 가중치를 설명하는 상위 층) 설계 필요
  • 걸리는 점 ③ — 속성 추출이 틀리면 뒤 단계가 모두 틀림. 비슷한 사람 쪽으로 기우는 것은 '그 사람다움'을 지우는 위험과 같은 문제
  • 걸리는 점 ④ — 기여가 온톨로지 설계에서 통계 모형 쪽으로 옮겨 갈 수 있음. 교수님과 무게중심 상의 필요
  • 두 논문이 우리 설계에 주는 뜻 ① — LLM의 몫은 "기록이 없을 때의 첫 짐작"까지. 개인 정보를 빼도 결과가 비슷했다는 것은 LLM이 아는 것이 그 사람이 아니라 상품 상식이라는 뜻 → 그 사람다움은 본인 기록으로 갱신하는 데서 나옴
  • 뜻 ② — 기록을 LLM에 더 보여 주는 방식은 잘 안 통함(근거 ②). "아카이빙해서 LLM에 넣기"가 아니라 "아카이빙해서 통계 모형을 갱신하기"로 가야 함
  • 뜻 ③ (우리에게 불리한 점) — 응답자 기록이 몇십 명분 있으면 과거 기록 기반 모형이 LLM 사전분포보다 낫다. 다작 리뷰어 자료를 쓰는 우리 설계에서는 이 기록 기반 모형(계층 베이즈)을 비교 기준에 반드시 넣어야 하고, 온톨로지가 거기에 무엇을 더하는지 보여야 함
  • 자료 차이 — 두 논문은 "여러 대안 중 하나를 고른" 선택 자료(교통수단, 항공권)를 씀. 우리 리뷰 자료는 별점이라 그대로 옮길 수 없음
  • 출처 — 수치는 발표 자료(수업 논문 발표 슬라이드)에서 옮김. 인용 전 원문 표와 대조 필요

자료 구성 가안

단위는 개인, 사람은 여러 명.

본 실험 — 다작 리뷰어 30~50명한 카테고리, 1인당 리뷰 100개 이상. 앞 시기로 채우고 뒤 시기 별점·리뷰를 예측
심층 사례 — 인터뷰 인물 1명가치 층까지 드러나는지 확인 (밀라논나 자료 활용)
세부 설명
  • 일반 리뷰를 섞으면 개인이 아니라 평균 소비자가 됨
  • 한 명만 하면 일반성을 말할 수 없음
  • 후보 공개 자료: Amazon Reviews 2023 (영어, 사용자별 리뷰 묶음·별점·상품 정보 포함)
  • 한계: 산 것만 평가해 별점이 높게 쏠림, 리뷰에는 가치 층이 잘 안 나옴, 한국어 자료는 별도 확인 필요

세부 설명
  • LLM은 기록을 보여 줘도 잘 못 배움 — Qiu 외(2025)에서 선택을 5번 보여 줘도 37% → 37%. 기록을 더 넣는 것만으로는 부족
  • 반대 증거가 있음 — Funhouse Mirrors에서 풍부한 개인 정보 조건(약 0.748)과 정보 없는 조건(약 0.734)은 거의 같았고, 파일럿에서도 발췌를 넣은 조건이 빈 LLM보다 낫지 않았음
  • 부류로 끌려감 — 비슷한 사람 자료는 평균 정확도를 올리지만, 그 사람이 부류와 다르게 생각하는 대목은 더 틀리게 만듦. 기업이 알고 싶은 것은 그 대목
  • 자기 주장을 무너뜨릴 수 있음 — 빌려서 정확해진다면 "한 사람 대체"가 아니라 세그먼트 모델. 협업 필터링을 비교 기준으로 반드시 포함
  • 쌓기와 꺼내 쓰기는 다름 — 자료가 늘면 검색 잡음도 늚
  • 오래된 기록은 해로울 수 있음 — 입장이 바뀐 사례가 이미 있음. 시점 가중 필요
  • 새 질문에도 종류가 있음 — 자료로 좋아지는 것은 이미 본 주제 근처뿐
  • 기여가 약함 — "더 넣었더니 좋아졌다"는 예상되는 결과. 그래서 질문을 "무엇을 근거로 답했는지 구분하고, 언제 빌리고 언제 보류할지"로 바꿈 (위 근거 등급)

세부 설명
  • 정밀도 90%·재현율 86%·F1 88%는 사람이 붙인 라벨로 학습했을 때의 최고 수치(선형 SVM)입니다. 원격 감독(자동 라벨) 조건의 수치는 규칙 기반 판정 자체가 86·81·83%, 자동 라벨로 학습한 모델이 최고 87·85·86%입니다. 논문의 주장은 "자동 라벨로도 손 라벨과 비슷하게 나온다"입니다.
  • "예방적 프레임"은 원문의 prognostic framing으로, 해결책과 수단을 제시하는 프레임입니다. "예후(처방) 프레임"이 뜻에 더 가깝습니다.
  • 개체 인식 단독 성능은 딥러닝 모델(ELMo+BiLSTM+CRF)이 더 높았지만(태그별 F1 80~98%), 최종 탐지에 가장 좋았던 추출 구성은 특징 기반 모델(CRF 개체 인식 + 로지스틱 관계 추출)이었습니다. 딥러닝 추출기를 넣으면 탐지 성능이 떨어졌습니다.
  • 단어 빈도(TF-IDF) 대비 우위는 정밀도에서 일관되고, 재현율은 TF-IDF가 더 높은 경우도 있습니다. "월등히"보다는 "정밀도가 꾸준히 높다"가 정확합니다.
