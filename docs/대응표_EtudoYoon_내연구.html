참고 논문을 설명 영상 대본의 7장면 순서로 정리하고, 같은 자리에 내 연구를 맞춰 본 틀입니다. 내 연구는 시작 전이라 빈칸은 "어떻게 찾을지"만 적었습니다.

1. Etudo & Yoon 논문 요약

급진 조직의 이념을 프레이밍 이론에 따라 온톨로지(TBO)로 구조화하고, 선전물에서 프레임을 자동으로 뽑아 채운 뒤(FDS), 라벨 없는 온라인 글이 그 이념과 얼마나 맞는지를 점수화해(FRDS) 사람이 학습용 라벨을 붙이지 않고도 급진 게시물과 그 이념을 가려내는 설계 연구.

2. 용어와 시스템 구조 — 번호 순서대로 작동 원리

핵심 약어 — 아티팩트
TBOTerror Beliefs Ontology
테러 신념 온톨로지
  • 급진 이념을 담는 틀(양식)
  • 프레임 하나 = (주어 대상, 관계, 목적어 대상)
  • 최상위 클래스 4개: 주체 · 프레임 · 대상 · 관계
  • 그림의 ①, 채워진 것은 ②
내 연구에서는 → 인물 입장 온톨로지
FDSFrame Discovery System
프레임 발견 시스템
  • 글에서 프레임을 뽑아 틀을 채우는 추출기
  • 대상 찾기(NER) → 관계 찾기(RE) 두 단계
  • 조직 선전물과 검사할 글 양쪽에 똑같이 적용
  • 그림의 ②와 ④
내 연구에서는 → 입장 추출기
FRDSFrame Resonance Detection System
프레임 공명 탐지 시스템
  • 글이 특정 이념과 맞는지 가리는 탐지 시스템 전체
  • FRP를 만들고 RBC로 판정하는 부분을 묶어 부르는 이름
  • 그림의 ⑤~⑧
내 연구에서는 → 충실도 검증기
FRPFrame Resonance Profile
프레임 공명 프로필
  • 글과 이념이 관계 종류별로 얼마나 겹치는지 적은 점수 벡터
  • 글 1건 × 조직 1개마다 하나
  • 어느 관계에서 겹쳤는지 보여 설명이 가능
  • 그림의 ⑥
내 연구에서는 → 충실도 프로필
RBCRule-Based Classifier
규칙 기반 분류기
  • FRP를 점수 하나로 요약해 자동으로 라벨을 붙이는 규칙
  • 규칙: 평균 점수가 충분히 높고, 관계 종류의 절반 이상에서 0이 아님
  • 원격 감독이 실제로 일어나는 곳
  • 그림의 ⑦
내 연구에서는 → 규칙 기반 충실/불충실 판정
함께 나오는 용어
CAFTCollective Action Framing Theory
집단행동 프레이밍 이론
  • 이 논문의 근거 이론
  • 이념 = 진단 프레임 + 예후 프레임 + 동기 프레임
  • "공명(resonance)" 개념의 출처
내 연구에서는 → 미정 (찾아야 함)
DSDistant Supervision
원격 감독
  • 사람 대신 지식 베이스가 학습용 라벨을 만드는 방식
  • 여기서는 채워진 TBO + RBC가 그 역할
내 연구에서는 → 본인 답 없이 온톨로지로 판정
NERNamed Entity Recognition
개체명 인식
  • 문장에서 대상(사람, 조직, 장소, 종교 등)을 찾는 기술
  • FDS의 첫 단계
내 연구에서는 → 주제 찾기
RERelation Extraction
관계 추출
  • 찾은 대상들 사이의 관계를 찾는 기술
  • FDS의 둘째 단계. 결과가 프레임 세 칸이 됨
내 연구에서는 → 극성·근거·말투 추출
Claimant(약어 아님)
주장 주체
  • 프레임을 말한 조직 또는 온라인 인물
  • TBO에서 "누구의 이념인가"를 구분하는 기준
내 연구에서는 → Person (인물)
TF-IDFTerm Frequency–Inverse Document Frequency
단어 빈도 기반 특징
  • 글을 단어 출현 빈도로 나타내는 기존 방식
  • 논문에서 FRP와 비교한 기준선
내 연구에서는 → 파일럿에서 쓴 유사도 계산

3. 원격 감독(Distant Supervision) 라벨링 — 단계별 세부

사람이 글을 읽고 라벨을 붙이는 대신, 채워진 온톨로지(지식 베이스)를 기준으로 라벨 없는 글에 "이 이념에 공명함 / 아님" 라벨을 자동으로 붙이는 과정입니다.

Etudo & Yoon의 과정
내 연구에서 같은 자리 (가안)
대본에서 고쳐 읽을 곳 4가지 — 논문 원문과 대조한 결과입니다.
세부 설명
  • 정밀도 90%·재현율 86%·F1 88%는 사람이 붙인 라벨로 학습했을 때의 최고 수치(선형 SVM)입니다. 원격 감독(자동 라벨) 조건의 수치는 규칙 기반 판정 자체가 86·81·83%, 자동 라벨로 학습한 모델이 최고 87·85·86%입니다. 논문의 주장은 "자동 라벨로도 손 라벨과 비슷하게 나온다"입니다.
  • "예방적 프레임"은 원문의 prognostic framing으로, 해결책과 수단을 제시하는 프레임입니다. "예후(처방) 프레임"이 뜻에 더 가깝습니다.
  • 개체 인식 단독 성능은 딥러닝 모델(ELMo+BiLSTM+CRF)이 더 높았지만(태그별 F1 80~98%), 최종 탐지에 가장 좋았던 추출 구성은 특징 기반 모델(CRF 개체 인식 + 로지스틱 관계 추출)이었습니다. 딥러닝 추출기를 넣으면 탐지 성능이 떨어졌습니다.
  • 단어 빈도(TF-IDF) 대비 우위는 정밀도에서 일관되고, 재현율은 TF-IDF가 더 높은 경우도 있습니다. "월등히"보다는 "정밀도가 꾸준히 높다"가 정확합니다.

6. 차이점

항목Etudo & Yoon내 연구영향
찾는 것이념과 일치하는 게시물본인 입장과 불일치하는 트윈 답방향만 반대, 구조는 같음
최종 목적분류(탐지)에서 끝남탐지 후 트윈을 고치는 데까지 씀"응용 시연" 절이 하나 더 필요
검사 대상사람이 쓴 게시물LLM이 만든 답그럴듯하게 꾸며져 있어 탐지가 더 어려울 수 있음
원격 감독의 필요이념이 많고 손 라벨이 비싸서 필수실험에서는 Holdout 본인 답이 정답 역할을 함"실제 사용 때는 본인 답이 없다"는 점으로 필요성을 세워야 함
규모여러 이념, 포럼 회원 602명인물 1명, 발화 381개일반성 주장이 약함 → 두 번째 인물 필요
근거 이론집단행동 프레이밍 이론으로 확정미정가장 큰 빈칸
추출 기술개체명 인식 + 관계 추출 모델을 직접 학습LLM에 스키마를 주고 추출기술 기여는 작음. 추출 정확도 검증이 중요
정답저자가 602명을 직접 읽고 라벨(평가용)본인의 이후 인터뷰 답 + 사람 채점 100쌍(평가용)코더 없이 가능하나 정답 품질을 따로 입증
온톨로지의 필요성이념을 구분하려면 구조가 필수단순 검증기로도 될 수 있음온톨로지 유무 비교를 먼저 해야 함
