급진 조직의 이념을 프레이밍 이론에 따라 온톨로지(TBO)로 구조화하고, 선전물에서 프레임을 자동으로 뽑아 채운 뒤(FDS), 라벨 없는 온라인 글이 그 이념과 얼마나 맞는지를 점수화해(FRDS) 사람이 학습용 라벨을 붙이지 않고도 급진 게시물과 그 이념을 가려내는 설계 연구.

2. 원격 감독(Distant Supervision) 라벨링 — 진행 과정

사람이 글을 읽고 라벨을 붙이는 대신, 채워진 온톨로지(지식 베이스)를 기준으로 라벨 없는 글에 "이 이념에 공명함 / 아님" 라벨을 자동으로 붙이는 과정입니다.

Etudo & Yoon의 과정
내 연구에서 같은 자리 (가안)
대본에서 고쳐 읽을 곳 4가지 — 논문 원문과 대조한 결과입니다.
세부 설명
  • 정밀도 90%·재현율 86%·F1 88%는 사람이 붙인 라벨로 학습했을 때의 최고 수치(선형 SVM)입니다. 원격 감독(자동 라벨) 조건의 수치는 규칙 기반 판정 자체가 86·81·83%, 자동 라벨로 학습한 모델이 최고 87·85·86%입니다. 논문의 주장은 "자동 라벨로도 손 라벨과 비슷하게 나온다"입니다.
  • "예방적 프레임"은 원문의 prognostic framing으로, 해결책과 수단을 제시하는 프레임입니다. "예후(처방) 프레임"이 뜻에 더 가깝습니다.
  • 개체 인식 단독 성능은 딥러닝 모델(ELMo+BiLSTM+CRF)이 더 높았지만(태그별 F1 80~98%), 최종 탐지에 가장 좋았던 추출 구성은 특징 기반 모델(CRF 개체 인식 + 로지스틱 관계 추출)이었습니다. 딥러닝 추출기를 넣으면 탐지 성능이 떨어졌습니다.
  • 단어 빈도(TF-IDF) 대비 우위는 정밀도에서 일관되고, 재현율은 TF-IDF가 더 높은 경우도 있습니다. "월등히"보다는 "정밀도가 꾸준히 높다"가 정확합니다.

5. 차이점

항목Etudo & Yoon내 연구영향
찾는 것이념과 일치하는 게시물본인 입장과 불일치하는 트윈 답방향만 반대, 구조는 같음
최종 목적분류(탐지)에서 끝남탐지 후 트윈을 고치는 데까지 씀"응용 시연" 절이 하나 더 필요
검사 대상사람이 쓴 게시물LLM이 만든 답그럴듯하게 꾸며져 있어 탐지가 더 어려울 수 있음
원격 감독의 필요이념이 많고 손 라벨이 비싸서 필수실험에서는 Holdout 본인 답이 정답 역할을 함"실제 사용 때는 본인 답이 없다"는 점으로 필요성을 세워야 함
규모여러 이념, 포럼 회원 602명인물 1명, 발화 381개일반성 주장이 약함 → 두 번째 인물 필요
근거 이론집단행동 프레이밍 이론으로 확정미정가장 큰 빈칸
추출 기술개체명 인식 + 관계 추출 모델을 직접 학습LLM에 스키마를 주고 추출기술 기여는 작음. 추출 정확도 검증이 중요
정답저자가 602명을 직접 읽고 라벨(평가용)본인의 이후 인터뷰 답 + 사람 채점 100쌍(평가용)코더 없이 가능하나 정답 품질을 따로 입증
온톨로지의 필요성이념을 구분하려면 구조가 필수단순 검증기로도 될 수 있음온톨로지 유무 비교를 먼저 해야 함
