## 1. 연구 배경 (Background)

### 1.1 문제 상황: 신뢰할 수 없는 페르소나 LLM
LLM에 인물 인터뷰를 주입해 만든 페르소나 LLM(디지털 트윈)은 고인 재현, 사용자 대리 응층, 인물 시뮬레이션 등에 쓰이고 있으나, 그 응층을 언제 믿어도 되는지에 대한 근거가 없다. 같은 문항에 여러 번 물으면 답이 흔들리는데, 이 흔들림이 (a) 온도·프롬프트·선택지 순서에서 오는 순수 잡음인지, (b) 인물 자료에 실제로 존재하는 양가감정의 반영인지 구분하는 방법이 확립되어 있지 않다.

### 1.2 선행연구와 빈틈
수업에서 다룬 네 연구가 1층(모델 경향)의 진단은 완성했다.

| 연구 | 한 것 | 못 한 것 |
|---|---|---|
| Twin-2K-500 | 기본 온도/조건 정확도 비교 (71.24% vs 71.72%) | 흔들림 해석 없음 |
| Funhouse Mirrors | 다섯 왜곡 진단, 최적 설정 T=0 | 사람 대응 검증은 벤치마크 수준 |
| Pezeshkpour & Hruschka | 순서 민감성 진단 + 10회 다수결 교정 (최대 8%p) | 반복의 한계(잡음만 줄임) |
| Fragile Preferences (Yin et al. 2026) | T=0 단일 질의로 선호 구분 불가, T=1 반복으로 robust/fragile/indifferent 분류 | 사람 자료 없음 — 2층 미검증 |

세 가지 명시적 빈틈:
1. **해석 이원론 미해결**: 같은 "흔들림" 현상을 잡음(다수결·T=0으로 교정)과 신호(반복 질의로 드러냄)라는 반대 해석이 공존하며, 구분 기준이 없음.
2. **2층 부재**: 실제 인물의 홀드아웃 발언을 가진 연구가 없어 "트윈이 신뢰할 수 있는가" 질문 자체가 정의되지 않음.
3. **데이터 무선별**: 페르소나 연구들은 인물 데이터를 통째로 프롬프트에 넣으며, 어떤 문서가 모델을 움직이는지 측정·선별한 연구가 없음.

추가로 본 연구가 확인한 제4의 문제: **기준선 오염**. 밀라논나는 공인이라 "빈 LLM(G0)"이 사전학습 지식으로 이미 그 인물을 부분적으로 알 수 있어, 종래의 "페르소나 있음/없음" 비교의 기준선 자체가 불안정하다.

### 1.3 접근 전환: 측정 → 설계
본 연구는 이 문제를 행동과학(현상 설명)이 아니라 **설계과학**으로 다룬다. 잡음과 신호의 구분은 순수한 지적 호기심이 아니라, "어떤 데이터를 넣고 어떤 문항에만 답하게 할 것인가"라는 **설계 의사결정**을 개선하기 위한 측정이며, 그 측정을 갖춘 페르소나 LLM 구축 절차 자체가 기여가 된다(Hevner et al. 2004: 지식은 아티팩트의 구축과 적용에서 얻어진다).

## 2. 문제 정의와 동기 (DSRM 1단계: Problem Identification & Motivation)

**실무 문제**: 페르소나 LLM 운용자는 (a) 어떤 응층을 신뢰할지, (b) 어떤 인터뷰 데이터를 넣을지, (c) 충돌하는 발언을 어떻게 처리할지 결정할 근거가 없다. 기존 교정법(다수결, T=0)은 흔들림 전체를 잡음으로 가정하고 눌러 버리므로, 신호(실제 양가감정)까지 소거할 위험이 있다.

**지식 문제**: 흔들림의 원인 분해(잡음/신호)를 문항 단위로 수행한 연구가 없고, 분해 결과를 데이터 선별·응층 정책에 연결한 연구도 없다.

---

## 3. 해결 목표 (DSRM 2단계: Objectives of the Solution)

- **O1 (측정)**: 문항 단위에서 페르소나 신호와 잡음을 분리하는 상대 지표(델타, 잡음 바닥, SNR)를 정의하고, 2×2 판정행렬(이동 크기 × 정확도)로 문항을 진단한다.
- **O2 (설계)**: 측정 결과를 구축 절차에 반영 — leave-one-out 문서 기여도 기반 데이터 큐레이션, 시간순 페르소나, SNR 임계 기반 선택적 응층 — 하여 기존 구축법(통째 주입 + 단일 응층)보다 홀드아웃 정확도와 커버리지-정확도 트레이드오프에서 우위인 페르소나 LLM을 만든다.
- **O3 (일반화)**: 측정 파이프라인을 인물 독립적으로 정식화해 다른 페르소나에 이식 가능함을 보이고, 설계 원칙(design principles)로 추상화한다.

## 4. 연구 질문 (Research Questions)

| RQ | 내용 | 산출물 연결 | 지위 |
|---|---|---|---|
| **RQ1 (진단)** | 페르소나 주입이 만드는 응층분포 이동(델타)은 순수 잡음과 어떻게 구분되는가? — 페르소나 신호 S(i), 잡음 바닥 N(i), SNR이 오염(G0이 이미 아는 것)과 미커버(데이터 부족)를 구별하는가? | 측정 파이프라인 | 주 |
| **RQ2 (설계/평가)** | 델타 기반 진단을 데이터 큐레이션과 선택적 응층에 반영하면, 홀드아웃 정확도와 risk-coverage 곡선에서 기존 구축법(통째 주입, T=0 단일, 20회 최빈값, 순서 셔플 평균)보다 우위인가? | 구축 절차 (아티팩트 본체) | 주 |
| **RQ3 (해석)** | 잉여 흔들림(G2가 G0 바닥 위로 튀어나오는 흔들림)은 인물의 실제 양가감정·시기별 입장 변화와 정렬되는가? | 시간순 페르소나 | 보조(탐색적) |
| **RQ4 (일반화)** | 측정 파이프라인은 다른 인물(가명/타 페르소나)에게 이식되어 같은 진단을 제공하는가? | 설계 원칙 | 보조(범위 명시 시) |

영문 표기 (논문용):
- **RQ1**: How can persona-induced response variation be distinguished from sampling noise at the item level, and does the resulting signal-to-noise metric discriminate contamination from data-undercoverage?
- **RQ2**: Does incorporating the delta-based diagnosis into persona data curation and selective answering improve holdout accuracy and the risk-coverage trade-off over baseline construction methods?
- **RQ3**: Does residual instability (G2 variance in excess of the G0 noise floor) align with the individual's documented ambivalence or position changes over time?
- **RQ4**: Is the measurement pipeline transferable to other personas?

## 5. 산출물 (Artifact)

**주 산출물**: 델타 기반 페르소나 충실도 프레임워크 (방법론 아티팩트 — 측정 파이프라인 + 구축 절차)

구성요소 5가지:
1. **3조건 기준선 설계**: G0(빈 LLM) / G1(가명 처리 인터뷰 — 이름·식별정보 제거) / G2(실명 인터뷰). G1로 기준선 오염과 페르소나 내용 효과를 분리.
2. **문항별 신호·잡음 지표**: S(i) = JSD(P0(i), P2(i)), N(i) = G0의 20회 흔들림, SNR(i) = S/N. 2×2 판정행렬(이동 크기 × 홀드아웃 정확도)로 문항을 4유형 분류(신호/왜곡/오염/미커버).
3. **데이터 큐레이션 절차**: leave-one-out로 인터뷰 문서별 기여도 측정 → 기여도 0·음수 문서 제외 → 축소된 프롬프트로 재구축.
4. **시간순 페르소나**: 잉여 흔들림 문항의 충돌 발언을 제거하지 않고 타임스탬프와 함께 구조화("2020년엔 A, 2024년엔 B").
5. **선택적 응층 정책**: SNR 임계 이상 문항만 응층, risk-coverage 곡선으로 임계 최적화(교차검증으로).

**인스턴시에이션**: 밀라논나 디지털 트윈(문항 × 조건 × 온도 × 순서 그리드로 구동).

**아티팩트 추상화 수준** (Gregor & Hevner 2013): 인스턴스(밀라논나 트윈) → 방법(측정·큐레이션 파이프라인) → 설계 원칙(§8). 논문은 방법 수준을 기여로 제시.

## 6. DSRM 프로세스 매핑 (Peffers et al. 2007)

| DSRM 단계 | 본 연구의 수행 | 산출 |
|---|---|---|
| 1. 문제 확인·동기 | 문헌 분석(§1) + 리뷰어 비판(02 문서 C/I/S/E 12항목) | 문제 정의(§2) |
| 2. 해결 목표 정의 | §3의 O1-O3 | 목표 명세 |
| 3. 설계·개발 | 아티팩트 v0: 측정 파이프라인(JSD·잡음 바닥·SNR 계산) + 큐레이션 스크립트 | 파이프라인 코드 |
| 4. 시연 | 파일럿: 문항 10-20개 × G0/G1/G2 × T=0 1회 + T=1 20회 × 순서 2종 (P1-P7 판정표) | 판정표 결과 |
| 5. 평가 | 본실험: 파일럿과 다른 문항으로 기준선 4종 비교(§7) | 평가 결과 |
| 6. 커뮤니케이션 | 논문 작성 | 초록·논문 |

**반복 주기**: 4→3으로 되돌아감(파일럿 결과로 설계 수정). 이는 데이터 우선 접근(02 문서)과 동일한 구조 — 주제(A/B/C)를 사전 고정하지 않고 파일럿 판정표 P1-P7로 살아남는 질문을 결정한 뒤 본실험(확증)으로 이어감. 탐색에 쓴 문항과 확증에 쓸 문항을 분리해 HARKing을 방지.

**파일럿 판정표 (P1-P7, 02·03 문서 통합)**
| # | 확인할 것 | 판정 |
|---|---|---|
| P1 | 흔들림 분포 모양 | 쌍봉 → 잡음/신호 두 집단(구분 가능). 단봉 → "혼합 비율"로 질문 수정 |
| P2 | G0 vs G2 분포 이동 | 이동 있음 → 델타 프레임 유효. 없음 → RQ1 재검토 |
| P3 | 다발 언급 문항 수 | H2/RQ3 실현 가능성 판정 |
| P4 | 흔들림-오답 대략 관계 | 없으면 RQ2의 교정 비교가 주축 |
| P5 | 순서 효과 크기 | 크면 순서 교정이 독립 결과 |
| P6 | G0 정확도가 우연 수준 초과인가 | 오염 확인 시 G1(가명) 조건 승격 |
| P7 | SNR 분포 | 대부분 낮으면 응층 1(큐레이션) 중심, 높으면 진단 프레임 중심 |

## 7. 평가 설계 (Evaluation)

### 7.1 평가 방법 매핑 (Hevner et al. 2004의 평가 접근)
- **실험적(통제실험)**: 본실험 — 문항 단위 통제 비교. 주 평가.
- **관찰(사례연구)**: 밀라논나 사례에 대한 심층 분석(2×2 행렬의 4사분면 사례 제시).
- **분석적(민감도 분석)**: JSD 외 발산 지표(KL, Wasserstein), 잡음 바닥 정의(20회 SD vs 엔트로피) 변경 시 결과 안정성.
- **서술적(정보에 입각한 논증)**: 설계 원칙의 타당성 논증.

### 7.2 기준선 4종 (모두 동일 홀드아웃 문항으로 비교)
1. 통째 주입 + T=0 단일 응층 (현행 관행)
2. 통째 주입 + T=1 20회 최빈값
3. 통째 주입 + 순서 셔플 평균
4. 큐레이션 + 선택적 응층 (본 연구의 아티팩트)

### 7.3 지표
- 홀드아웃 정확도 (문항 단위, 커버리지 공변량 통제)
- risk-coverage 곡선 (AUC) — 임계값은 교차검증으로 선택(02 문서 S3 대응)
- 문항 유형별(2×2 사분면) 정확도 분해 — "어떤 문항에서 왜 우위인가"를 보여줌

### 7.4 분석 단위와 검정력
- 분석 단위 = 문항 (20회 호출은 독립 표본 아님). 문항 수 확정이 최우선 — 파일럿 전에 문항 pool 크기 확인, 가능하면 100개 이상, 불가하면 범위와 신뢰구간 명시.

## 8. 지식 기여와 설계 원칙 (Knowledge Contribution)

### 8.1 기여 유형 (Gregor & Hevner 2013의 지식 기여 프레임)
- **개선(improvement)**: 기존 페르소나 구축법(통째 주입) 대비 정확도·커버리지 트레이드오프 개선.
- **외도(exaptation)**: 환각 탐지의 일관성 기반 불확실성 추정(Manakul et al. 2023; Kuhn et al. 2023)과 Fragile Preferences의 반복 질의를 페르소나 충실도 측정이라는 새 영역으로 이식.
- 문제 영역(페르소나 LLM)은 성숙, 해법 지식(델타 측정)은 기성 → **improvement + exaptation** 위치.

### 8.2 설계 원칙 (초안, 평가 후 확정)
- **DP1 (상대 측정)**: 페르소나 효과는 절대 지표가 아니라 기준모델(G0) 대비 분포 이동으로 측정할 것.
- **DP2 (오염 분리)**: 기준모델이 인물을 이미 알 수 있으므로 가명 조건(G1)을 두어 공개 지식 효과와 인터뷰 효과를 분리할 것.
- **DP3 (잡음 바닥 명시)**: 흔들림은 조건별 잡음 바닥(G0 분산) 대비 잉여분으로 해석할 것.
- **DP4 (선별 주입)**: 인물 데이터는 통째 주입하지 말고 문서별 기여도를 측정해 선별할 것.
- **DP5 (충돌의 구조화)**: 인물 발언 간 충돌은 제거하지 말고 시간 정보로 구조화할 것.
- **DP6 (거부 가능성)**: 신뢰 구간 밖 문항은 답하지 않을 권한을 시스템에 줄 것.

## 9. 타당성 위협과 대응 (02 문서 12항목 통합)

| 위협 | 대응 | 반영 단계 |
|---|---|---|
| C1 흔들림 지표 혼재 | 소스별 분해: G0 분산(잡음 바닥) vs G2 잉여분 vs 순서 효과 | 아티팩트 구성요소 2 |
| C2 사람 흔들림 코딩 주관성 | 채점자 블라인드 + 코헨 카파 보고 | RQ3 분석 |
| C3 척도 수준 불일치 | 발산 지표로 통일(JSD), 대안 지표 민감도 분석 | §7.1 분석적 평가 |
| C4 G0 구성 타당도 | G1(가명) 조건 신설로 오염/내용 분리 | 아티팩트 구성요소 1 |
| I1 커버리지 교란 | 문항별 근거 발언 수를 공변량으로 통제 | §7.3 |
| I2 H2 선택 편향 | 다발 vs 단발 문항 주제 분포 층화, RQ3는 탐색적으로 강등 | RQ3 지위 |
| I3 순서 2종의 한계 | 순서 효과는 집단 수준에서만 해석 | §7 분석 계획 |
| I4 답지 누출 | 답지와 입력 발언의 출처 분리 명시 | 데이터 준비 |
| S1 검정력 | 문항 수 사전 확정(100+ 목표) | §7.4 |
| S2 다중 비교 | 주분석 사전 지정(RQ2의 기준선 비교), 나머지 탐색 표기 | 본실험 설계 |
| S3 사후 임계값 | risk-coverage 임계는 교차검증 | §7.3 |
| E1 n=1 | 사례연구로 프레이밍 + RQ4로 이식성 검토(가능 시 1-2인물 추가) | §4 RQ4 |

## 10. 연구 범위의 명시
- 인물 1명(밀라논나), 모델 1종, 언어 1개 — 일반화 주장은 설계 원칙 수준으로 한정.
- RQ4는 시간·자원 허용 시에만 수행(가명 처리 인터뷰 1-2건 추가).
