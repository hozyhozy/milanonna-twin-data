## 3. 계산

### 3-1. 자료 범위 (문항마다, 호출 없음)
- `n_sub`: 문항과 같은 하위 주제의 Train 발화 수
- `n_top`: 같은 상위 주제의 Train 발화 수
- `sim_max`: 가장 가까운 Train 발췌와의 유사도(보조 지표)
- 구간: **없음**(n_sub = 0) / **적음**(1~3) / **충분**(4 이상). 구간 경계는 분포를 보고 한 번만 정하고 문서에 남긴다.

### 3-2. 검증 점수 (답마다)
| 코드 | 점수 | 호출 |
|---|---|---|
| D0 | 무작위 | 없음 |
| D2 | 검색 유사도 `sim_max` (낮을수록 불충실 예상) | 없음 |
| D3 | 단순 검증기 점수 (§2의 4) | 300 |
| **D4** | **온톨로지 간이판**: ① 답의 극성 − 같은 하위 주제 본인 발화의 평균 극성(절댓값), ② 본인 극성 범위를 벗어났는지, ③ `n_sub`가 0이면 상위 주제로 대체하고 불확실 가산 | 없음 |
| D3+D4 | 두 점수의 단순 결합(순위 평균) | 없음 |

답의 극성은 `judge_*.jsonl`의 응답 태그를 쓴다(이미 있음).

### 3-3. 정답 라벨
- **불충실** = 판정 stance < 40. 민감도 확인을 위해 30·50 기준과 "valence 차이 ≥ 2" 기준도 함께 보고.
- 본인 재답변의 stance가 평균 56이었으므로, 40 미만은 본인 변동 범위보다 확실히 낮은 구간으로 본다.

### 3-4. 지표
- **Q-A**: 검증 점수별 AUROC, 문항 단위 부트스트랩 95% 구간. 보조로 "점수 하위 30%를 버렸을 때 남은 답의 평균 stance".
- **Q-B**: 자료 범위 구간 × 조건(G0·G1·G2)의 평균 stance 표와 그림. 구간별 G2 − G0 차이. 본인 천장(56)을 기준선으로 표시.

## 4. 판정 규칙 (돌리기 전에 고정)

### Q-A
| 결과 | 판정 | 다음 |
|---|---|---|
| D3+D4가 D3보다 AUROC 0.03 이상 높음 | 통과 — 온톨로지가 단순 검증을 **보완** | v3 유지 |
| D4 ≥ D3 − 0.03 이고 D4 > 0.60 | 통과 — 호출 없이 **비슷한 성능** | v3 유지, 비용 우위를 기여로 |
| 그 외 | 실패 | 주제를 더 잘게 나눠 1회 재시도. 그래도 실패면 v2로 복귀 |
| D3·D4 모두 0.55 이하 | 판단 보류 | 라벨(판정 모델) 문제일 수 있음 → 0-1(판정 교체) 후 다시 |

### Q-B
| 결과 | 해석 | 연구에 주는 뜻 |
|---|---|---|
| 자료 범위가 클수록 G2 − G0가 커짐 | 트윈은 자료가 닿는 곳에서만 쓸모 있다 | 자료 범위를 적용 경계(context 주장)와 보류 규칙의 근거로 |
| 구간과 무관하게 평평 | 자료가 닿아도 답에 반영되지 않는다 | 문제는 범위가 아니라 검색·생성. 발췌 전략·전체 삽입(0-6) 쪽으로 무게 이동 |
| 범위 "없음"에서 G2가 G0보다 낮음 | 페르소나가 자료 밖 질문에서 오히려 해롭다 | 긴장 T2(포괄 ↔ 정확)의 직접 근거. 보류 규칙의 필요성 |

## 5. 한계 (결과를 읽을 때)

- **라벨이 DeepSeek 판정**이다. 게이트 0-1(다른 패밀리 재채점) 전에는 방향 확인용.
- **50문항**이라 자료 범위 구간당 10~20문항. 구간 차이는 추세로만 읽는다.
- **주제 목록의 거칠기**에 D4가 민감하다. 한 주제 안에 긍정·부정 발화가 섞이면 평균이 0 근처로 뭉친다 → 하위 주제별 극성 표준편차를 함께 보고.
- 간이판은 **극성 편차와 자료 범위만** 쓴다. 근거 지지·말투는 본 구현에서 추가.
- D3와 태깅 모두 생성 모델과 같은 패밀리다.
