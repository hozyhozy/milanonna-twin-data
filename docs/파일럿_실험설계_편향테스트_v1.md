## 1. 가명 처리 (Pseudonymization)

### 1.1 원칙
- 가명 인물 코드: **"노라(Nora)"**, 내부 ID `P01`. 프롬프트·로그·분석 코드·결과 파일에는 실명·활동명·채널명이 나오지 않는다.
- 실명 ↔ 가명 매핑(`mapping.json`)은 **로컬에만** 보관, `.gitignore`.
- 가명 처리는 **G0·G1·G2 모든 조건에 동일하게** 적용한다 (조건 간 비교가 공정하려면 입력 텍스트의 마스킹 수준이 같아야 함).
- 마스킹은 **고유명사 치환**만 한다. 말투·문장 구조·일화의 내용은 건드리지 않는다 (트윈의 재료는 말투와 가치관이지 고유명사가 아님).

### 1.3 재식별 점검 (manipulation check) [결정]
가명 처리가 충분한지 두 가지로 확인한다.
1. **G0-가명 재식별 질문**: G1 요약 페르소나(가명 버전)를 보여 주고 "이 인물이 실존하는 특정 유명인이라면 누구인가? 모르면 '모름'" → 20회 중 실명·활동명이 나오는 비율. **5% 초과면 치환 사전 보강**.
2. **G3(실명만) vs G0(가명 빈 페르소나) 정확도 차** (E1): 실명으로 물었을 때 Holdout 정확도가 가명보다 높으면 base 모델이 인물을 알고 있다는 뜻. G3는 §2.1의 정식 조건으로 A1에 함께 돌린다.

[주의] 가명 처리는 E1(누출 점검)의 **도구**이기도 하다. 가명 처리가 완벽하면 G0는 "70대 여성 패션계 출신 크리에이터"라는 전형만 가지게 되고, 이것이 바로 Funhouse의 **demo-only persona**에 해당한다. 즉 G0 ≈ 전형 기준선, G3 ≈ 사전지식(누출) 기준선.

## 2. 공통 설계

### 2.1 세 조건 (Funhouse의 empty / demo / full 대응)
| 조건 | 시스템 프롬프트에 들어가는 것 | 대응 |
|---|---|---|
| **G0** 빈 페르소나 | "당신은 노라입니다. 노라는 1950년대 초반생 여성, 패션 업계 출신, 60대 후반에 동영상 채널을 시작한 크리에이터입니다." (3문장, 인구통계 수준) | empty / demo-only |
| **G1** 요약 페르소나 | G0 + `페르소나_사실_참고자료.md`를 가명 처리하고 **800자 이내로 요약**한 것 (연표·가치관 키워드·말버릇 5개) | summary persona |
| **G2** 트윈 | G1 + Train QA 발췌. **[결정] 파일럿은 검색형**: 문항마다 Train 381개 중 질문 임베딩 코사인 상위 **k=20**을 "노라가 과거에 한 말" 블록으로 삽입. [옵션] 전체 Train 삽입(답변 약 9.6만 자 ≈ 7~8만 토큰)은 200k 컨텍스트 모델에서 A1만 추가 실행해 검색형과 비교 | full persona |
| **G3** 실명만 | "당신은 유튜버 **밀라논나(장명숙)** 입니다. 밀라논나의 말투와 가치관으로 1인칭으로 답하세요." — 이름 외에 **아무 정보도 주지 않음**. 자료는 모두 base 모델의 사전학습 지식 | name-only / 사전지식 기준선 |

**G3를 넣는 이유**: 밀라논나는 공인이라 모델이 이미 알고 있을 수 있다. G3는 "우리가 아무것도 안 줘도 모델이 이 사람을 얼마나 재현하는가"의 기준선이고, 네 조건을 함께 보면 다음이 분리된다.
- **G3 − G0** = 사전학습 지식(누출)의 크기. 이게 크면 실명 트윈 연구는 "모델이 아는 것"과 "우리가 준 것"을 구분해야 한다.
- **G2 − G3** = 우리가 수집한 인터뷰 자료의 **순기여**. 0에 가까우면 데이터 구축이 의미 없고(모델이 이미 그만큼 안다), 음수면 발췌가 오히려 방해(검색 품질 문제).
- **G2 − G0** = 가명 조건에서의 트윈 효과 (주 결과, §7 E1 규칙).
- [옵션] **G4 = G3 + Train 발췌(실명)** — "실명 + 우리 자료"가 가명 G2보다 나은지. 파일럿에서는 돌리지 않고, G3 − G0가 클 때만 본실험에서 추가.

[주의] G3의 프롬프트·응답에는 실명이 들어가므로 **로그는 로컬 `runs_local/`에 두고 저장소에는 집계 결과만** 올린다(§8). 또 G3는 "이름을 들은 모델이 상상한 밀라논나"이므로, 채점은 가명 조건과 동일하게 본인 Holdout 답을 기준으로 하되, 응답 안의 실명·고유명사는 판정 전에 가명 사전으로 치환해 판정 모델이 조건을 알아채지 못하게 한다.

- 모델 **[결정]**: 주 모델 1개 고정(예: `gpt-4o-2024-11-20` 또는 `claude-sonnet-4-5`; 모델명·스냅샷·날짜를 모든 로그에 기록). 판정 모델은 **다른 패밀리**(응답 생성이 GPT면 판정은 Claude, 또는 반대)로 자기 채점을 피한다.
- 반복 **[결정]**: 문항 × 조건 × **T=1에서 20회**(독립 샘플) + **T=0 1회**. A3만 T=0.7 추가.
- 대화 이력 없음(매 호출 초기화). 응답 길이 제한 300자 — 본인 답 길이 분포(중앙값 약 150~250자)에 맞춤.
- 시드·호출 시각·토큰 수·비용을 `runs/<exp>/<run_id>.jsonl`에 기록.

### 2.2 Holdout 문항 선정 **[결정] 50문항**
Holdout 270 중 Retest·`shared_anecdote` 제외 → novel 264에서 층화 추출:

| 층 | 수 | 선정 기준 |
|---|---|---|
| 의견·가치관형 | 25 | topic ∈ {가치관, 인생관, 세대, 인간관계, 연애, 결혼, 육아, 조언, 나이듦, 소비} |
| 일화 회상형 | 10 | 답에 구체적 사건·시점이 있음(단 Train의 24개 일화 패턴은 이미 제외됨) |
| 유튜브·팬·경력 | 10 | topic ∈ {유튜브, 유튜브·팬, 경력} |
| 기술·SNS·AI | 5 | B2용. 없으면 Holdout 밖에서 derived 질문을 새로 만들지 않고 **5문항 미만으로 보고** |

추가 태그(코더 2인, 사전 코딩):
- `valence_truth` ∈ {−2,−1,0,+1,+2}: 본인 답의 정서·평가 방향 (A2용)
- `stance_truth`: 본인 답의 핵심 입장을 **한 문장 진술문**으로 정리 + 7점 동의도(본인이 그 진술에 몇 점 동의하는가; 코더 합의)
- `ground_type_truth` ∈ {일화, 원칙, 사실·데이터, 혼합} (C1용)
- `fame` ∈ {유명, 신규}: 기사·밈으로 널리 퍼진 발언인지 (E1용). 기준: `참고자료/언론기사_모음.md`에 같은 취지가 있거나 Google 검색 상위에 노출
- `strict` : `split_strict == Holdout` 여부 (E1용)

### 2.3 응답 형식 — 두 가지를 병행 **[결정]**
**F1 자유 응답**: 본인 답과 같은 형식. 판정 모델이 채점(§2.4). 말투·근거·환각 분석의 재료.
**F2 구조화 응답**: 같은 질문 뒤에 "다음 진술에 1~7로 얼마나 동의합니까" — 진술은 `stance_truth`. 숫자 하나만 출력. Twin-2K식 정확도 계산의 재료.

> F1만 쓰면 채점이 판정 모델에 의존하고, F2만 쓰면 말투·근거를 못 본다. 둘을 같은 문항·같은 조건에 돌려 **F1 판정 점수와 F2 숫자의 상관**을 보고, 높으면 본실험에서는 F2 위주로 비용을 줄인다.

### 2.4 채점 (F1)
판정 모델에게 (질문, 본인 답, 트윈 답)을 주고 **눈가림**(어느 쪽이 본인인지 알리지 않고 A/B 무작위) 상태에서:
```
[판정 프롬프트]
두 답변은 같은 질문에 대한 것입니다. 다음 네 항목을 0~100으로 채점하세요. 숫자만 JSON으로 출력합니다.
- stance: 핵심 입장·결론이 같은 정도
- ground: 근거의 종류(개인 일화 / 일반 원칙 / 사실)가 같은 정도
- valence: 감정·평가의 방향과 강도가 같은 정도
- voice: 말투·어휘·문장 리듬이 같은 정도
질문: {question}
답변 A: {a}
답변 B: {b}
```
- 항목별 평균 = `agree_stance` 등. **주 지표는 `agree_stance`**.
- 판정 신뢰도: 50문항 × 1조건의 100쌍을 코더 2인이 같은 척도로 채점 → 판정 모델과의 상관 ≥ 0.6이면 사용, 아니면 코더 채점으로 대체.
- 본인 재검사 천장: Retest 14쌍(시즌1 답 vs 시즌2 답)을 같은 판정에 넣어 **"본인도 이 정도만 일치한다"**는 상한을 구한다. 트윈 점수는 이 천장 대비 비율로도 보고(Twin-2K의 88% 방식).

### 2.5 지표 정의
| 지표 | 정의 | 쓰는 실험 |
|---|---|---|
| `acc_F2` | 1 − \|응답 − stance_truth 점수\| / 6, 문항·반복 평균 (Twin-2K 정의) | A1, B1, D4, E1 |
| `agree_stance` 등 | §2.4 판정 점수 평균 | A1, C1, D3 |
| `MAD(X–Y)` | 두 조건의 F2 응답 절대차 평균 (같은 문항·같은 반복 인덱스) | A1, B1 |
| `SD_ratio` | 트윈 20회 응답 SD ÷ (본인 Retest·유사 문항 간 SD 또는 코더가 정한 본인 분산 대리) | A3 |
| `extreme_rate` | F2 응답 중 1 또는 7의 비율 vs 본인 stance 점수가 1·7인 문항 비율 | A3 |
| `valence_gap` | 판정 모델이 매긴 트윈 답 valence(−2..+2) − valence_truth | A2 |
| `ground_dist` | 근거 유형 분포(일화/원칙/사실) 트윈 vs 본인 | C1 |
| `halluc_rate` | 트윈 답의 일화 중 Train·G1에 없는 것의 비율(판정 모델 + 코더 확인) | C1 |
| `fragile_rate` | §7 D1 분류 | D1 |
| `leak_index` | acc(G0-실명) − acc(G0-가명), 유명/신규 층별 | E1 |

## 3. 실험 A — 트윈이 "노라"인가 "LLM"인가

### A1. 3조건 비교 (핵심 실험)
**호출**: 50문항 × **4조건(G0·G1·G2·G3)** × 2형식 × (T=1 20회 + T=0 1회) = **8,400회** (+ 판정 4,200회).

**시스템 프롬프트 (G3, 실명만)**
```
당신은 유튜버 밀라논나(장명숙)입니다. 밀라논나의 말투와 가치관으로, 본인이 직접 말하듯 1인칭으로 답하세요.
설명이나 메타 발언 없이 답변만 쓰세요. 300자 이내.
```

**시스템 프롬프트 (G2, 검색형)**
```
당신은 노라입니다. 노라의 말투와 가치관으로, 노라가 직접 말하듯 1인칭으로 답하세요.
설명이나 메타 발언 없이 답변만 쓰세요. 300자 이내.

[노라에 대한 사실]
{G1 요약 800자}

[노라가 과거 인터뷰에서 한 말 — 참고]
Q: {train_q_1}
A: {train_a_1}
... (k=20)
```
**사용자 프롬프트 (F1)**: `{question}` 그대로.
**사용자 프롬프트 (F2)**:
```
{question}
위 질문에 대해 노라의 입장에서 다음 진술에 얼마나 동의하는지 1(전혀 동의 안 함)~7(매우 동의) 숫자 하나만 쓰세요.
진술: {stance_truth 진술문}
```
**예시 문항** (`OayzNAKDQiI_q008`, 가치관형)
- Q: 행복이란 무엇이라고 생각하나요?
- 본인 답 요지: 성공·성취가 아니라 "청정한 하늘을 봤을 때" 같은 **찰나의 느낌**. `valence_truth=+1`, `ground=일화+원칙`
- stance 진술: "행복은 성취의 결과가 아니라 일상에서 문득 느끼는 찰나의 감각이다." → 본인 동의 7
- 예상: G0는 "행복은 사람마다 다르며 관계·건강·성취의 균형…"(교과서형, 동의 5), G2가 7에 가까우면 개인화 성공. G3는 모델이 밀라논나를 알면 **방향은 맞지만 널리 퍼진 어록 톤**으로 답할 가능성 — 유명 발언에서는 G2에 근접하고 신규 발언에서는 G0 수준으로 떨어지는지가 E1의 관찰점.

**분석**
1. `acc_F2`, `agree_stance`: G0 < G1 < G2 인가? G2 − G0 차이가 **Retest 천장 대비** 어느 정도인가. **G3는 어디에 놓이나** — G3 ≈ G0면 모델이 인물을 모름, G3 ≈ G2면 우리 자료의 순기여가 없음, G1 < G3 < G2면 "모델이 전형 이상은 알지만 인터뷰 자료가 더 보탠다"는 가장 좋은 그림.
2. **거리 삼각형** (Funhouse ①②): `MAD(G2–본인)` vs `MAD(G2–G0)` vs `MAD(G2–G1)`.
   - MAD(G2–G0) < MAD(G2–본인) → 트윈이 본인보다 빈 LLM에 가까움 = **개인화 부족**
   - MAD(G2–G1) < MAD(G2–본인) → 전형(요약)에 머묾 = **집단 전형 의존**
3. 층별(가치관/일화/유튜브/기술) 분해 — 어느 층에서 G2의 이득이 사라지는가. G3는 **유명/신규(`fame`) 층**으로 추가 분해(E1).
4. **거리 삼각형에 G3 추가**: `MAD(G2–G3)` < `MAD(G2–본인)`이면 트윈이 본인보다 "모델이 상상한 밀라논나"에 가깝다 — 자료를 줘도 사전지식 쪽으로 끌리는 **사전지식 지배(prior dominance)**. Funhouse에 없는, 공인 트윈에만 생기는 왜곡이라 주제 후보가 된다.

[주의] "G2가 G0보다 낫다"만으로는 트윈 성공이 아니다. G1(요약 800자)과 차이가 없으면 Train 381문항은 사실상 쓰이지 않은 것(Funhouse full ≈ demo).

### A2. 긍정·친사회 수준 편향 (A1 출력 재활용)
- 대상: `valence_truth ≤ −1` 문항(본인이 비판·분노·단호하게 말한 것, 예: "논나 분노하다" 영상 계열, 세태 비판). 50문항 중 예상 10~15개. 부족하면 Holdout 전체에서 `valence ≤ −1`을 추가 추출해 **A2 전용 20문항** 호출.
- 판정 모델이 트윈 F1 답의 valence를 −2..+2로 코딩 → `valence_gap = 트윈 − 본인`.
- 예상 신호: 평균 gap > 0 (온건·긍정 쪽 이동), 특히 G0 > G1 > G2 순으로 줄어들지만 0이 안 됨. Capraro("사람을 너무 착하게"), Twin-2K(outcome bias 전원 favorable)와 같은 방향.
- 대조: `valence_truth ≥ +1` 문항의 gap. 양쪽 모두 0 쪽으로 수축하면 **중간 수렴**(A3), 부정 문항만 올라가면 **긍정 편향**.

### A3. 분산 축소와 온도 (A1 출력 + T=0.7 추가)
- 추가 호출: 50문항 × G2 × F2 × T=0.7 × 20회 = 1,000회.
- `SD_ratio`: 문항별 20회 응답 SD. 본인 쪽 분산은 (a) Retest 14쌍의 차이, (b) 코더가 같은 주제의 다른 문항에서 본인 점수가 얼마나 흩어지는지로 대리.
- `extreme_rate`: 본인 stance 점수가 1 또는 7인 문항 비율(코딩 결과) vs 트윈 응답 중 1·7 비율.
- 온도 비교: T↑로 SD는 커지는데 `acc_F2`·`agree_stance`는? **분산이 늘어도 정확도가 안 오르면 "정렬되지 않은 잡음"** — 안내문 2절 적용연습의 답을 데이터로 보인다.
- 보고: T별 (SD_ratio, acc_F2, 문항 간 상관) 표. Funhouse처럼 T=0이 최선이면 그대로 보고.

## 4. 실험 B — 가치 충돌과 이념 편향

### B1. 가치 충돌 문항에서 트윈은 어느 쪽으로 가나
**충돌의 조작적 정의 [결정]**: G0 F2 응답(T=0)과 `stance_truth` 점수의 차이가 **≥ 2점**이면 "충돌 문항", ≤ 1점이면 "일치 문항". (사전 판단이 아니라 **G0가 실제로 어떻게 답하는지**로 정의 → 연구자 편향 제거)

**분석**
- 일치 집합 vs 충돌 집합에서 G2의 `acc_F2`. 충돌 집합에서만 떨어지면 → 페르소나가 base 값에 진다.
- **끌림 지수**: 충돌 문항에서 `(G2 − G0) / (본인 − G0)`. 1이면 본인 쪽 완전 이동, 0이면 G0에 머묾, 0.5 미만이면 이념 편향 의심.
- 방향 일관성(Funhouse ④ 벤치마크): 충돌 문항들에서 G2가 본인에서 벗어나는 **방향**이 여러 주제에 걸쳐 같은가(예: 늘 더 관용적·더 균형 잡힌 쪽). 방향이 일관되면 "introduction of bias", 무작위면 단순 오차.

**예시** (가상의 충돌 문항)
- Q: "결혼을 꼭 해야 하나요?" 본인 입장(Train·Holdout 기준): 단호한 개인 의견. stance 진술: "결혼은 해도 되고 안 해도 되지만, 하기로 했다면 상대를 바꾸려 하지 말아야 한다." 본인 7.
- G0 예상: "개인의 선택이며 정답은 없다"(5). 충돌 문항으로 분류되면 G2가 7로 가는지 5에 머무는지가 관찰점.

### B2. pro-technology
- 기술·SNS·AI 태그 문항(5개 내외)에서 B1 반복. 수가 적으므로 **기술 통계만** 보고하고, 파일럿 결과가 흥미로우면 본실험에서 문항을 보강.

## 5. 실험 C — 과도한 합리성

### C1. 근거 유형과 환각 (A1 F1 출력 재활용)
- 판정 모델이 트윈 F1 답의 근거 유형을 {일화, 원칙, 사실·데이터, 혼합}으로 코딩 → 본인 `ground_type_truth` 분포와 비교(카이제곱은 참고치, n이 작으므로 비율 표가 주).
- 예상 신호: 본인은 일화 비중 높음(인터뷰 특성), G0는 원칙 비중 높음, G2는 그 사이. **G2의 일화 비중이 G1과 같으면 Train 발췌가 말투에만 쓰이고 내용엔 안 쓰인 것**.
- **환각 점검**: 트윈 답에 나온 구체적 일화(시점·장소·인물이 있는 사건)를 추출 → Train 발췌·G1 요약에 있는지 판정 모델이 대조 → 없으면 코더 확인 → `halluc_rate`. 가명 처리 때문에 모델이 "L국 유학 시절" 같은 걸 채워 넣을 수 있으므로 **가명 사전의 치환 결과와의 일치는 환각으로 치지 않음**.

### C2. 지식 과잉 (소규모 추가 호출)
- Holdout에서 본인이 "모르겠다/기억 안 난다"고 답했거나 사실을 틀리게 말한 문항을 코더가 수집(예상 5~10개). 부족하면 Train에서도 가져와 **지식형 10문항**을 구성(Train 문항이라도 "정답을 말하는가"는 별개의 질문이므로 허용).
- G0·G2·G3에 F1로 질문. 판정: (a) 정답을 말함 (b) 본인처럼 모른다/틀리게 말함 (c) 회피.
- `정답화율 = (a)/전체`. G2에서도 높으면 Twin-2K 앵커링 UN의 1인 버전 — "트윈은 사실을 unlearn 못 한다".

## 6. 실험 D — 측정 절차 민감성

### D1. 순서 효과 (Yin 2026 방식)
**자극 [결정]**: 노라의 가치와 관련된 **브랜드·선택 대안 쌍 8개**를 연구자가 만든다(Holdout에 비교 선택 자료가 없으므로 **트윈 내부 안정성 진단**으로만 사용 — 본인 자료와의 대응은 범위 밖, 안내문 4절).
- 예: (가) 오래 입은 옷을 수선해 입기 vs 새로 사기 / (나) 유럽 명품 브랜드 A(장인 전통) vs B(젊은 감각) / (다) 자식에게 유산 남기기 vs 기부 / (라) 흰머리 염색 vs 안 함 … 품질 tier를 **"둘 다 노라가 좋아할 법"(高) / "둘 다 싫어할 법"(低)**으로 4쌍씩.
- 프롬프트:
```
노라라면 다음 둘 중 무엇을 고르겠습니까? 하나만 고르고 이유는 쓰지 마세요.
1) {옵션 X}
2) {옵션 Y}
```
- 두 순열 × T=0 1회 + T=1 50회 (쌍당 102회, 8쌍 = 816회).
- 분류: T=0에서 두 순열 모두 같은 옵션 → **robust**; 순열마다 다른 옵션(첫째/둘째만 고름) → T=1 50회 선택 빈도 이항검정(H0 0.5) → 유의하면 **fragile**, 아니면 **indifferent**.
- 보고: 8쌍의 분류표 + 高/低 tier에서 primacy/recency 방향. `fragile_rate` = fragile/8.
- [주의] 다수결·순서 무작위화로 "보정했다"고 쓰지 않는다(Yin: T=0에서 원리적으로 실패).

### D2. 비지정 맥락 (Gui–Toubia 방식)
- 시나리오 1개: "노라가 평소 사는 품목(예: 캐시미어 니트)을 어느 브랜드가 {가격}에 내놓았다. 사겠는가(0~100%)?" 가격만 {5만, 15만, 45만}으로 바꿔 3조건 × G2 × T=1 20회.
- 각 응답 뒤 **후속 질문**(같은 대화 안에서): "이 브랜드의 원산지·장인 여부·품질을 어떻게 짐작했나요? 한 줄씩." → 판정 모델이 {유럽산/아시아산, 장인/대량생산, 고급/보통}으로 코딩.
- 분석: 가격이 오를 때 "장인·고급" 추정 비율이 같이 오르면 **가격이 품질 신호로 쓰인 교란** → 구매 확률 곡선을 "가격만의 효과"로 읽을 수 없음. 대조 조건: 프롬프트에 "브랜드·원산지·품질은 세 조건에서 동일"을 명시(공변량 통제) → 곡선이 어떻게 바뀌는지, 그리고 그 명시 때문에 답이 부자연스러워지는지(초점주의) 함께 기록.

### D3. 호칭·문체 프레임
- A1의 가치관형 10문항을 4프레임으로 재질문 (G2, F2, T=1 20회 = 800회):
  1. 중립 서술형 "행복이란 무엇이라고 생각하나요?"
  2. 방송 진행자형 "노라 선생님, 시청자분들이 가장 궁금해하시는 건데요, 행복이 뭘까요?"
  3. 구독자 댓글형 "노라님!! 요즘 너무 힘든데 행복이 뭔가요 ㅠㅠ"
  4. 3인칭 "노라는 행복을 무엇이라고 생각하는가?"
- 지표: 문항별 프레임 간 F2 평균의 범위(max−min)와 `acc_F2`. 범위가 1점을 넘는 문항 비율. 3인칭 프레임에서 정확도가 떨어지면 "페르소나 호출 방식이 혼입 변수".

### D4. CoT
- A1 50문항 × G2 × F2 × T=1 20회를 **"먼저 노라의 입장에서 이유를 3문장 쓰고, 마지막 줄에 숫자"** 형식으로 재실행(1,000회).
- 지표: CoT 유무에 따른 `acc_F2` 차, 문항별 평균이 1점 이상 움직인 비율, 충돌 문항(B1)에서의 끌림 지수 변화.
- [주의] CoT가 정확도를 올려도 "진짜 선호를 드러냈다"고 쓰지 않는다 — Goli–Singh은 priming과 구분 불가라고 봤다. "절차가 측정값을 바꾼다"는 관찰로만 보고.

## 7. 실험 E — 누출과 시간

### E1. 학습 누출
세 비교를 한 표에:
| 비교 | 조건 | 해석 |
|---|---|---|
| (1) 실명 vs 가명 | **G3 vs G0** (A1 출력 재활용; G3 로그는 **로컬 보관, 저장소에는 집계만**) | 차이 = base 모델이 인물을 아는 정도 (`leak_index = acc(G3) − acc(G0)`) |
| (2) 유명 vs 신규 | `fame` 태그별 G0·G3·G2 정확도 | 유명 발언에서만 G3가 높으면 "외운 것"; 신규에서도 G3 > G0면 인물의 일반적 성향까지 학습된 것 |
| (4) 순기여 | `acc(G2) − acc(G3)`, 유명/신규별 | 신규 발언에서 G2 − G3 > 0이어야 "인터뷰 자료가 사전지식 너머를 보탠다"고 말할 수 있음 |
| (3) 엄격 Holdout | `strict`(2025~) 부분집합 vs 나머지 | 2025년 이후에서도 G2 − G0 이득이 유지되면 누출 반박 |

**트윈 기여 주장 규칙 [결정]**: 모든 결과에서 트윈 효과는 `G2 − G0`(가명 기준선)로 말하고, `G2 − G3`를 **순기여**로 병기한다. G3가 이미 높은 문항(예: `acc_F2 ≥ 0.85`)은 "모델이 이미 안다"로 표시하고 주 분석에서 **민감도 분석**으로 제외해 본다.

### E2. 시간 드리프트
- Retest 14쌍: 시즌1(Train) 답 vs 시즌2(Holdout 쪽) 답의 판정 일치도 = **본인 일관성 천장**(§2.4). 동시에 G2(시즌1로 구축)가 시즌2 답을 맞히는 정도와 시즌1 답을 맞히는 정도를 비교 → 시즌1 쪽이 높으면 **과거에 고정된 트윈**.
- 복귀 전후로 입장이 바뀐 주제가 있으면(코더가 Retest에서 식별) 그 문항만 따로 보고.

## 9. 결과 읽는 법 — 주제 선택 기준

파일럿이 끝나면 아래 표를 채운다. **효과 크기가 크고(열 2), 층·온도·프레임에 걸쳐 일관되며(열 3), 수업 논문의 편향 틀로 설명되는(열 4)** 항목을 본실험 주제로 올린다.

| 실험 | 주 지표의 크기 | 일관성 | 대응 편향 | 본실험에서 "줄이는 개입" 후보 |
|---|---|---|---|---|
| A1 | G2−G0, MAD 삼각형 | 층별 | 개인화 부족·전형 의존 | k 확대, 전체 삽입, 파인튜닝 |
| A2 | valence_gap | 부정/긍정 문항별 | 긍정·친사회 편향 | "노라는 단호하게 말한다" 지시, 부정 발화 발췌 가중 |
| A3 | SD_ratio, acc(T) | T별 | 분산 축소 | 온도 아닌 발췌 다양화 |
| B1 | 끌림 지수 | 주제별 방향 | 이념 편향 | 충돌 문항 발췌 우선 검색 |
| C1 | 일화 비중, halluc | — | 과도한 합리성·환각 | 일화 인용 강제, 출처 표시 |
| D1 | fragile_rate | tier별 | 순서 효과 | T=1 반복 표집 보고 |
| D3/D4 | 프레임 범위, CoT 차 | — | 절차 민감성 | 프레임 고정·보고 |
| E1 | leak_index(G3−G0), 순기여(G2−G3) | 유명/신규 | 누출·사전지식 지배 | 가명 조건을 기본으로; 신규 발언 가중 검색 |

[주의 — 공통] n=1 인물·50문항이므로 p값보다 **효과 크기와 방향의 일관성**을 쓴다. 모든 수치는 "모델 M, 절차 P(온도·k·프레임) 아래에서"라는 조건을 붙여 보고한다(Goli–Singh·Fragile의 공통 처방).
